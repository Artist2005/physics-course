    1. Хімічна термодинаміка: закон Гесса, вільна енергія Гіббса та константа рівноваги

    Згідно із законом Гесса тепловий ефект хімічної реакції при сталому тиску дорівнює зміні ентальпії системи ΔH = ∑ νᵢ ΔH°_f(прод) − ∑ νⱼ ΔH°_f(реаг) і не залежить від проміжних стадій перетворення. Проте сам знак ΔH ще не визначає можливості самочинного перебігу реакції в ізобарно-ізотермічних умовах (P, T = const), оскільки необхідно врахувати зміну ентропії ΔS. Універсальним критерієм напрямку хімічного процесу є зміна вільної енергії Гіббса:

    ΔG = ΔH − TΔS,    ΔG° = −RT ln K

    Реакція відбувається самочинно в прямому напрямку при ΔG < 0, досягає стану динамічної хімічної рівноваги при ΔG = 0 і є термодинамічно забороненою в прямому напрямку при ΔG > 0. Коли ΔH і ΔS мають однаковий знак, напрямок реакції змінюється при проходженні через характеристичну температуру інверсії Tрівн = ΔH / ΔS. Відповідно до принципу Ле Шательє-Брауна підвищення температури зміщує рівновагу в бік ендотермічного процесу (ΔH > 0), а підвищення загального тиску зміщує газофазну систему в бік меншої сумарної кількості молів газу.

    2. Хімічна кінетика: порядки реакцій, період напівперетворення та рівняння Арреніуса

    Швидкість гомогенної елементарної стадії за законом діючих мас пропорційна добутку молярних концентрацій реагентів у степенях їхніх кінетичних порядків: v = −d[A] / dt = k[A]^n. Інтегрування диференціального рівняння для нульового (n = 0, насичений гетерогенний каталіз), першого (n = 1, мономолекулярний розпад) та другого (n = 2, бімолекулярні зіткнення) порядків виявляє якісно різну залежність періоду напівперетворення t1/2 від початкової концентрації [A]₀.

    Кінетичний порядок n Диференціальне рівняння Інтегральний закон [A](t) Період напівперетворення t1/2
    Нульовий (n = 0) −d[A]/dt = k [A](t) = [A]₀ − kt t1/2 = [A]₀ / (2k)
    Перший (n = 1) −d[A]/dt = k[A] [A](t) = [A]₀ exp(−kt) t1/2 = ln 2 / k ≈ 0.693 / k
    Другий (n = 2) −d[A]/dt = k[A]² 1/[A](t) = 1/[A]₀ + kt t1/2 = 1 / (k[A]₀)

    Експоненціальне зростання константи швидкості з температурою описується рівнянням Арреніуса k(T) = A · exp(−Ea / RT), де Ea позначає енергію активації перехідного комплексу, а A враховує частоту та просторову орієнтацію зіткнень. Введення гомогенного чи гетерогенного каталізатора спрямовує реакцію новим маршрутом зі зниженим бар'єром E'_a < Ea, прискорюючи одночасно пряму й зворотну стадії без зміни рівноважної константи K.

    3. Протолітична рівновага, буферні розчини та електрохімічні системи

    У розведених водних розчинах при 25 °C іонний добуток води становить Kw = [H⁺][OH⁻] = 1.0 × 10⁻¹⁴, а водневий показник визначається як pH = −lg a(H⁺) ≈ −lg[H⁺]. Буферні системи зі слабкої кислоти HA та її спряженої солі A⁻ підтримують стабільне значення pH під час розведення або додавання невеликих порцій сильних кислот і лугів згідно з рівнянням Гендерсона-Гассельбаха: pH = pKa + lg([A⁻] / [HA]).

    В електрохімічних колах просторове розділення напівреакцій окиснення на аноді та відновлення на катоді перетворює вільну енергію реакції ΔG = −zFℰ безпосередньо в електричну роботу. Рівноважний електродний потенціал залежить від активностей окисненої й відновленої форм за рівнянням Нернста E = E° + [RT / (zF)] ln([Ox] / [Red]), а при примусовому проходженні постійного струму силою I крізь електролізер маса виділеної на електроді речовини підпорядковується об'єднаному закону Фарадея m = (M · I · t) / (z · F), де стала Фарадея дорівнює F = 96485.3 Кл/моль.

    4. Приклади розв'язування розрахункових задач

    Задача 1. Зміна pH ацетатного буферного розчину при додаванні сильної кислоти

    До 1.00 л ацетатного буферного розчину, який містить 0.20 моль етанової кислоти CH₃COOH (pKa = 4.76) та 0.20 моль натрій етаноату CH₃COONa, додали 0.020 моль газоподібного хлороводню HCl без помітної зміни об'єму. Обчисліть початковий і кінцевий pH буфера та порівняйте зі зміною pH при додаванні тієї самої порції HCl до 1.00 л чистої води.

    Розв'язання. Оскільки початкові концентрації компонентів рівні ([A⁻]₀ = [HA]₀ = 0.20 моль/л), початковий показник становить pH₀ = 4.76 + lg(0.20 / 0.20) = 4.76. Сильна кислота кількісно протонує ацетат-іони: CH₃COO⁻ + H⁺ → CH₃COOH, тому нові рівноважні кількості дорівнюють [A⁻] = 0.20 − 0.02 = 0.18 моль/л та [HA] = 0.20 + 0.02 = 0.22 моль/л. За рівнянням Гендерсона-Гассельбаха pH = 4.76 + lg(0.18 / 0.22) = 4.76 + lg(0.818) = 4.76 − 0.087 ≈ 4.67 (зсув становить лише ΔpH = −0.09). У чистій воді (pH₀ = 7.00) додавання 0.020 моль/л HCl знижує показник до pH = −lg(0.020) = 1.70, тобто на 5.30 одиниці.

    Відповідь. у буфері pH змінюється з 4.76 до 4.67; у чистій воді з 7.00 до 1.70.

    Задача 2. ЕРС гальванічного елемента Даніеля-Якобі при нерівноважних концентраціях

    Обчисліть електрорушійну силу елемента Zn | ZnSO₄ (0.010 М) || CuSO₄ (1.00 М) | Cu при температурі T = 298.15 К, якщо стандартні електродні потенціали становлять E°(Zn²⁺/Zn) = −0.763 В та E°(Cu²⁺/Cu) = +0.340 В.

    Розв'язання. Стандартна ЕРС елемента з двохелектронним переходом (z = 2) дорівнює ℰ° = E°_кат − E°_анод = 0.340 − (−0.763) = 1.103 В. При 298.15 К коефіцієнт перед десятковим логарифмом у рівнянні Нернста становить (2.3026 RT) / F = 0.05916 В. Для сумарної реакції Zn + Cu²⁺ → Zn²⁺ + Cu реакційна частка дорівнює Q = [Zn²⁺] / [Cu²⁺] = 0.010 / 1.00 = 10⁻². Підставляємо у рівняння Нернста: ℰ = ℰ° − (0.05916 / 2) lg Q = 1.103 − 0.02958 · (−2) = 1.103 + 0.059 = 1.162 В.

    Відповідь. ℰ = 1.162 В.
