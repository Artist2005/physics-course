Класична механіка: закони збереження імпульсу й енергії та динаміка обертання

Фундаментальні інтеграли руху дозволяють визначати швидкості, траєкторії та енергетичні втрати механічних систем без інтегрування нелінійних сил під час короткочасних взаємодій. У цьому розділі подано строге виведення законів збереження імпульсу, повної механічної енергії та моменту імпульсу з розрахунковими прикладами.

1. Імпульс механічної системи та теорема про рух центра мас

Для системи з N матеріальних точок масами mᵢ та миттєвими швидкостями vᵢ в інерціальній системі відліку сумарний вектор імпульсу визначається геометричною сумою P = ∑ mᵢvᵢ = M·v_c, де M = ∑ mᵢ становить повну масу системи, а v_c описує швидкість її центра мас. Згідно з другим і третім законами Ньютона внутрішні сили взаємодії між частинками попарно рівні за модулем і протилежні за напрямком: Fᵢₖ = −Fₖᵢ. Після додавання рівнянь руху всіх точок внутрішні сили взаємно знищуються, залишаючи диференціальний закон зміни імпульсу: dP / dt = F_зовн.

Якщо векторна сума всіх зовнішніх сил дорівнює нулю або її проєкція на вибрану вісь зникає (F_зовн,x = 0), відповідна компонента повного імпульсу залишається незмінною в часі: P_x = const. Це твердження справедливе навіть тоді, коли всередині системи діють дисипативні сили сухого чи 'зкого тертя, відбувається пластична деформація або хімічний вибух. Механічна енергія при цьому може переходити у внутрішню теплову енергію, проте швидкість центра мас замкненої системи не змінюється.

2. Центральний удар двох куль і коефіцієнт відновлення Ньютона

Розглянемо прямий центральний удар двох однорідних куль масами m₁ та m₂, які до контакту рухаються вздовж осі Ox зі швидкостями v₁ і v₂. Ступінь пружності матеріалу під час деформації кількісно характеризується безрозмірним коефіцієнтом відновлення e = |u₂ − u₁| / |v₁ − v₂|, де u₁ та u₂ позначають проєкції швидкостей після розльоту, причому 0 ≤ e ≤ 1. Поєднання збереження імпульсу m₁v₁ + m₂v₂ = m₁u₁ + m₂u₂ зі співвідношенням Ньютона дає загальні аналітичні формули кінцевих швидкостей:

u₁ = [m₁v₁ + m₂v₂ − e·m₂(v₁ − v₂)] / (m₁ + m₂),    u₂ = [m₁v₁ + m₂v₂ + e·m₁(v₁ − v₂)] / (m₁ + m₂)

При абсолютно пружному зіткненні (e = 1) кінетична енергія системи повністю відновлюється після фази пружного стиснення. Якщо ж кулі мають однакову масу (m₁ = m₂) і зазнають абсолютно пружного центрального удару, формули спрощуються до повного обміну швидкостями: u₁ = v₂ та u₂ = v₁. Саме цей граничний режим спостерігається в ланцюжку сталевих куль колиски Ньютона.

При абсолютно непружному ударі (e = 0) тіла після контакту рухаються як єдине ціле зі спільною швидкістю центра мас u = (m₁v₁ + m₂v₂) / (m₁ + m₂). Частина початкової кінетичної енергії необоротно перетворюється на теплоту деформації ΔQ, величина якої визначається через зведену масу μ = m₁m₂ / (m₁ + m₂) та відносну швидкість зближення:

ΔQ = E_k0 − E_k = ½ · [m₁m₂ / (m₁ + m₂)] · (v₁ − v₂)² · (1 − e²)

3. Робота консервативних сил, потенціальна енергія та рух по похилій площині

Консервативними називають сили, елементарна робота яких не залежить від форми траєкторії і визначається лише початковим та кінцевим положеннями тіла. До них належать однорідна сила тяжіння (E_p = mgh), гравітаційне притягання Ньютона (E_p = −GMm / r), кулонівська електростатична взаємодія та сила пружності Гука (E_p = ½kx²). За наявності неконсервативної сили ковзного тертя F_тер = μ_к N зміна повної механічної енергії дорівнює роботі дисипативних сил: (E_k2 + E_p2) − (E_k1 + E_p1) = −F_тер · s.

Для бруска масою m на похилій площині з кутом нахилу α нормальна реакція опори становить N = mg cos α, а скочувальна складова сили тяжіння дорівнює F_∥ = mg sin α. Тіло залишається у стані спокою за умови tg α ≤ μ_сп. Якщо кут перевищує критичний кут тертя α_кр = arctg μ, брусок рухається вниз із постійним прискоренням a = g(sin α − μ cos α).

4. Динаміка обертального руху твердого тіла та момент інерції

Коли абсолютно тверде тіло котиться по поверхні без проковзування, між лінійною швидкістю його осі v та кутовою швидкістю обертання ω виконується кінематичний з'зок v = ωR. За теоремою Кеніга повна кінетична енергія тіла складається з енергії поступального руху центра мас та енергії обертання навколо осі, що проходить через центр мас:

E_k = ½mv² + ½Iω² = ½mv²(1 + β),    де β = I / (mR²)

Безрозмірний геометричний коефіцієнт β визначає розподіл маси відносно осі обертання. Чим більша частка маси зосереджена на периферії тіла, тим більша частина потенціальної енергії mgh витрачається на розкручування і тим меншим виявляється лінійне прискорення скочування з похилої площини a = g sin α / (1 + β).

Матеріальна точка або брусок без тертя 0 0 g sin α

Суцільний круговий циліндр або диск (1/2) mR² 0.50 (2/3) g sin α ≈ 0.667 g sin α

Тонкостінний обруч або труба mR² 1.00 (1/2) g sin α = 0.500 g sin α

5. Момент імпульсу та гіроскопічна прецесія

Вектор моменту імпульсу точки відносно полюса визначається векторним добутком L = [r × p], а його швидкість зміни дорівнює головному моменту зовнішніх сил: dL / dt = M_зовн. Для швидко обертової симетричної дзиґи з власним моментом імпульсу L = I_s ω_s, вісь якої нахилена під кутом θ до вертикалі й закріплена на відстані l від центра мас, момент сили тяжіння M = mgl sin θ спрямований горизонтально й перпендикулярно до вектора L. Оскільки вектор приросту dL = M dt ортогональний до самого L, модуль моменту імпульсу не змінюється, а вісь гіроскопа описує конус навколо вертикалі з кутовою швидкістю прецесії Ω_пр = mgl / (I_s ω_s).

6. Приклади роз'зування розрахункових задач

Задача 1. Втрата механічної енергії при частково пружному зіткненні

Сталева куля масою m₁ = 0.60 кг, що рухається горизонтально зі швидкістю v₁ = 4.0 м/с, наздоганяє кулю масою m₂ = 0.40 кг, яка рухається в тому самому напрямку зі швидкістю v₂ = 1.5 м/с. Коефіцієнт відновлення під час удару дорівнює e = 0.80. Визначте швидкості обох куль після удару та кількість виділеної теплоти ΔQ.

Роз'зання. Обчислюємо повний імпульс системи до зіткнення: P = 0.60 · 4.0 + 0.40 · 1.5 = 2.40 + 0.60 = 3.00 кг·м/с. Відносна швидкість зближення становить v₁ − v₂ = 2.5 м/с, а повна маса m₁ + m₂ = 1.00 кг. Підставляємо числові значення у формули швидкостей після удару: u₁ = [3.00 − 0.80 · 0.40 · 2.5] / 1.00 = 3.00 − 0.80 = 2.20 м/с; u₂ = [3.00 + 0.80 · 0.60 · 2.5] / 1.00 = 3.00 + 1.20 = 4.20 м/с. Зведена маса дорівнює μ = (0.60 · 0.40) / 1.00 = 0.24 кг. Виділена теплота деформації: ΔQ = 0.5 · 0.24 · (2.5)² · (1 − 0.80²) = 0.12 · 6.25 · 0.36 = 0.27 Дж.

Відповідь. u₁ = 2.20 м/с, u₂ = 4.20 м/с, ΔQ = 0.27 Дж.

Задача 2. Машина Атвуда з урахуванням інерції блока

Через однорідний циліндричний блок масою M = 0.80 кг перекинуто нерозтяжну невагому нитку, до кінців якої підвішено вантажі масами m₁ = 1.50 кг та m₂ = 1.10 кг. Тертя в осі блока відсутнє. Знайдіть прискорення вантажів і сили натягу обох віток нитки (g = 9.81 м/с²).

Роз'зання. Запишемо рівняння другого закону Ньютона для обох вантажів та рівняння моментів для суцільного циліндричного блока з моментом інерції I = ½MR²: m₁g − T₁ = m₁a, T₂ − m₂g = m₂a, (T₁ − T₂)R = Ia / R = ½Ma. Додаючи три рівняння, отримуємо загальну формулу прискорення: a = (m₁ − m₂)g / (m₁ + m₂ + ½M). Підстановка чисел дає a = (1.50 − 1.10) · 9.81 / (1.50 + 1.10 + 0.40) = 3.924 / 3.00 = 1.31 м/с². Сили натягу лівої та правої віток становлять T₁ = m₁(g − a) = 1.50 · (9.81 − 1.31) = 12.75 Н та T₂ = m₂(g + a) = 1.10 · (9.81 + 1.31) = 12.23 Н.

Відповідь. a = 1.31 м/с², T₁ = 12.75 Н, T₂ = 12.23 Н.
