РОЗДІЛ VIII · ТЕОРЕТИЧНИЙ ДОВІДНИК ТА ЗАДАЧНИК

Довідник фізичних сталих CODATA, одиниць системи СІ та похибок лабораторних вимірювань

Сучасна Міжнародна система одиниць СІ спирається на фіксовані числові значення семи фундаментальних констант природи. Цей розділ містить довідникові таблиці для роз'зування задач і алгоритм обробки прямих та непрямих вимірювань у віртуальному і реальному практикумі.

1. Фундаментальні фізичні та фізико-хімічні сталі (редакція СІ / CODATA)

З 20 травня 2019 року визначення всіх семи основних одиниць СІ (секунди с, метра м, кілограма кг, ампера А, кельвіна К, моля моль і кандели кд) зафіксовані через точні числові значення швидкості світла у вакуумі c, сталої Планка h, елементарного електричного заряду e, сталої Больцмана k_B та сталої Авогадро N_A. Завдяки цьому зазначені константи в системі СІ не мають експериментальної невизначеності.

2. Розмірність основних похідних величин та перевірка однорідності формул

Будь-яке фізично коректне аналітичне співвідношення мусить бути розмірнісно однорідним: ліва й права частини рівняння, а також усі доданки алгебраїчної суми мають однакову розмірність через основні одиниці L (довжина), M (маса), T (час), I (сила струму), Θ (температура) і N (кількість речовини). Аргументи трансцендентних функцій (експоненти exp(x), логарифмів ln x, тригонометричних функцій sin x, cos x) завжди є строго безрозмірними комбінаціями, як-от показник Арреніуса −E_a / (RT) або фаза біжучої хвилі (kx − ωt).

3. Оцінювання похибок прямих і непрямих лабораторних вимірювань

Для серії з n незалежних прямих вимірювань величини x₁, x₂, ..., x_n найкращою незміщеною оцінкою істинного значення є середнє арифметичне ⟨x⟩ = (1/n) ∑ xᵢ, а середньоквадратичне відхилення середнього обчислюється за формулою Бесселя s_{⟨x⟩} = √[ ∑(xᵢ − ⟨x⟩)² / (n(n − 1)) ]. Повна абсолютна похибка поєднує випадкову складову (множник Стьюдента t_{α, n−1}) та приладову похибку шкали Δ_прил: Δx = √[(t_{α,n−1} s_{⟨x⟩})² + Δ_прил²].

Якщо шукана величина обчислюється непрямо за степеневою формулою виду Y = C · x^a · y^b / z^c, відносна похибка результату ε_Y = ΔY / |Y| у лінійному наближенні для незалежних вхідних величин визначається квадратичним додаванням зважених відносних похибок:

ε_Y = ΔY / Y = √[ (a · Δx / x)² + (b · Δy / y)² + (c · Δz / z)² ]

4. Приклад розрахунку похибки непрямого вимірювання

Задача. Визначення прискорення вільного падіння за допомогою математичного маятника

Під час лабораторної роботи довжина нитки математичного маятника виміряна міліметровою лінійкою і становить L = 0.995 ± 0.002 м, а час N = 50 повних коливань за секундоміром дорівнює t = 100.1 ± 0.3 с. Обчисліть експериментальне значення g та його абсолютну й відносну похибки.

Роз'зання. Період одного коливання становить T = t / N = 100.1 / 50 = 2.002 с, а відносна похибка періоду збігається з відносною похибкою повного часу: ΔT / T = Δt / t = 0.3 / 100.1 = 0.0030 (0.30 %). Із формули Гюйгенса T = 2π√(L / g) виражаємо g = 4π²L / T². Підстановка середніх значень дає g = 4 · (3.14159)² · 0.995 / (2.002)² = 39.281 / 4.0080 = 9.801 м/с². Відносна похибка довжини становить ΔL / L = 0.002 / 0.995 = 0.0020 (0.20 %). Оскільки період входить у квадраті (b = 2), його внесок подвоюється: ε_g = √[ (0.0020)² + (2 · 0.0030)² ] = √[ 4×10⁻⁶ + 36×10⁻⁶ ] = √(40×10⁻⁶) ≈ 0.0063 (0.63 %). Абсолютна похибка становить Δg = 9.801 · 0.0063 ≈ 0.06 м/с².

Відповідь. g = (9.80 ± 0.06) м/с² (відносна похибка 0.63 %).
