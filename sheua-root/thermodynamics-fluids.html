Механіка рідин і газів та молекулярна термодинаміка: від закону Архімеда до циклу Карно

Макроскопічні параметри рідин і газів, зокрема статичний тиск, 'зкість, температура та ентропія, є наслідком колективного руху й міжмолекулярної взаємодії величезної кількості частинок. Розділ поєднує класичну гідродинаміку суцільного середовища зі статистичною фізикою Максвелла та законами термодинаміки.

1. Гідростатичний тиск, закон Архімеда та капілярні явища

У нерухомій нестисливій рідині густиною ρ_р тиск на глибині h зростає за лінійним законом P(h) = P₀ + ρ_р gh, де P₀ позначає зовнішній атмосферний тиск на вільній поверхні. Різниця сил гідростатичного тиску на нижню та верхню грані зануреного тіла створює вертикальну виштовхувальну силу Архімеда F_A = ρ_р g V_зан, де V_зан дорівнює о'му витісненої рідини. Суцільне однорідне тіло густиною ρ_т < ρ_р спливає до стану статичної рівноваги біля ватерлінії, при якій частка зануреного о'му дорівнює відношенню густин: V_зан / V = ρ_т / ρ_р.

На межі поділу рідини, газу й твердої стінки діють сили поверхневого натягу з питомою поверхневою енергією σ (Н/м). Викривлення поверхні рідини в тонкому циліндричному капілярі радіусом r породжує додатковий тиск Лапласа ΔP = 2σ cos θ / r, де θ є крайовим кутом змочування. При повному або частковому змочуванні (θ < 90°) увігнутий меніск втягує стовпчик рідини на висоту Жюрена h = 2σ cos θ / (ρ_р gr).

2. Рівняння нерозривності потоку, закон Бернуллі та 'зке обтікання Стокса

Для стаціонарної ламінарної течії ідеальної нестисливої рідини о'мна витрата крізь довільний поперечний переріз труби залишається сталою: Q_V = S₁v₁ = S₂v₂ = const. Застосування теореми про зміну механічної енергії до виділеного елемента трубки течії приводить до інтеграла Бернуллі: сума статичного тиску P, динамічного напору ½ρv² та нівелірного гідростатичного тиску ρgy зберігається вздовж лінії течії:

P + ½ρv² + ρgy = const

У звуженій горловині горизонтальної труби Вентурі швидкість потоку зростає обернено пропорційно до площі перерізу, тому статичний тиск у вузькому перерізі падає на величину ΔP = ½ρ(v₂² − v₁²). Окремим наслідком рівняння Бернуллі є формула Торрічеллі для швидкості витікання струменя з малого отвору у відкритому широкому резервуарі на глибині h нижче рівня рідини: v = √(2gh).

У реальних 'зких середовищах за малих чисел Рейнольдса (Re = ρvd / η ≪ 1) куля радіусом r, що рухається зі швидкістю v у рідині з динамічною 'зкістю η (Па·с), зазнає лінійної сили опору Стокса F_c = 6πηrv. Під час вертикального осідання кульки густиною ρ_т вага зрівноважується сумою сили Архімеда та опору Стокса, після чого встановлюється стала гранична швидкість v_уст = 2r²g(ρ_т − ρ_р) / (9η).

3. Молекулярно-кінетична теорія ідеального газу та розподіл Максвелла

Основне рівняння молекулярно-кінетичної теорії по'зує тиск розрідженого газу з концентрацією молекул n = N / V і середньою кінетичною енергією їхнього поступального теплового руху: P = (1/3)nm₀⟨v²⟩ = nk_BT, де k_B = 1.380649 × 10⁻²³ Дж/К позначає сталу Больцмана. Перехід до кількості речовини ν = m / M та універсальної газової сталої R = N_A k_B = 8.3145 Дж/(моль·К) дає рівняння стану Менделєєва-Клапейрона PV = νRT.

У стані термодинамічної рівноваги модулі швидкостей молекул молярної маси M розподілені за статистичним законом Максвелла, якому відповідають три характерні швидкості теплового руху: найімовірніша v_p = √(2RT / M), середня арифметична ⟨v⟩ = √(8RT / πM) та середньоквадратична v_кв = √(3RT / M), між якими завжди виконується нерівність v_p < ⟨v⟩ < v_кв.

4. Перший і другий закони термодинаміки та цикл Карно

Внутрішня енергія ідеального газу з числом ступенів вільності молекули i (i = 3 для одноатомних, i = 5 для жорстких двоатомних і i = 6 для багатоатомних нелінійних молекул) визначається виключно абсолютною температурою: U = (i/2)νRT. Перший закон термодинаміки стверджує, що підведена до газу кількість теплоти δQ витрачається на приріст внутрішньої енергії dU та виконання газом макроскопічної роботи δA = P dV.

Ізопроцес в ідеальному газі (ν = const) Інваріант стану Робота газу A Перший закон термодинаміки
Ізохорний процес V = const, P / T = const 0 Q = ΔU = (i/2)νRΔT
Ізобарний процес P = const, V / T = const P(V₂ − V₁) = νRΔT Q = [(i + 2)/2]νRΔT
Ізотермічний процес T = const, PV = const νRT ln(V₂ / V₁) ΔU = 0, Q = A
Адіабатний процес (γ = (i+2)/i) δQ = 0, PV^γ = const −ΔU = (P₁V₁ − P₂V₂) / (γ − 1) A = −ΔU

Згідно з теоремою Карно з-поміж усіх циклічних теплових машин, які працюють між нагрівником з абсолютною температурою T₁ та холодильником з температурою T₂ < T₁, максимальний термічний коефіцієнт корисної дії має оборотний цикл із двох ізотерм і двох адіабат: η_max = (Q₁ − Q₂) / Q₁ = (T₁ − T₂) / T₁ = 1 − T₂ / T₁.

5. Приклади роз'зування розрахункових задач

Задача 1. Перепад статичного тиску в горизонтальному витратомірі Вентурі

Горизонтальним трубопроводом тече вода густиною ρ = 1000 кг/м³. Діаметр широкої ділянки труби дорівнює d₁ = 60 мм, а діаметр звуженої горловини становить d₂ = 30 мм. У широкому перерізі швидкість потоку дорівнює v₁ = 1.20 м/с, а манометричний тиск становить P₁ = 140 кПа. Визначте швидкість і тиск води у вузькій горловині.

Роз'зання. За рівнянням нерозривності v₂ = v₁(S₁ / S₂) = v₁(d₁ / d₂)² = 1.20 · (60 / 30)² = 1.20 · 4 = 4.80 м/с. Із рівняння Бернуллі для горизонтальної осі y₁ = y₂ знаходимо тиск у горловині: P₂ = P₁ − ½ρ(v₂² − v₁²) = 140000 − 500 · (23.04 − 1.44) = 140000 − 500 · 21.60 = 140000 − 10800 = 129200 Па = 129.2 кПа.

Відповідь. v₂ = 4.80 м/с, P₂ = 129.2 кПа.

Задача 2. Робота та теплообмін ідеальної машини Карно

Ідеальна теплова машина працює за оборотним циклом Карно між нагрівником із температурою t₁ = 227 °C та холодильником із температурою t₂ = 27 °C. За один цикл робоче тіло виконує корисну механічну роботу A = 16.0 кДж. Обчисліть термічний ККД циклу, кількість теплоти Q₁, отриману від нагрівника, і теплоту Q₂, передану холодильнику.

Роз'зання. Переводимо температури у шкалу Кельвіна: T₁ = 227 + 273 = 500 К, T₂ = 27 + 273 = 300 К. Коефіцієнт корисної дії дорівнює η = (500 − 300) / 500 = 0.40 (40 %). З означення η = A / Q₁ отримуємо підведену теплоту Q₁ = 16.0 / 0.40 = 40.0 кДж. Кількість теплоти, віддана холодильнику за цикл, становить Q₂ = Q₁ − A = 40.0 − 16.0 = 24.0 кДж.

Відповідь. η = 40 %, Q₁ = 40.0 кДж, Q₂ = 24.0 кДж.
