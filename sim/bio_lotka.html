Ecosystem Dynamics: Lotka–Volterra Predator–Prey Oscillations & Trophic Energy Transfer

"Coupled interactions between prey x(t) and predators y(t) generate sustained periodic oscillations in which predator population peaks systematically lag behind prey peaks by a quarter cycle."

Question
The Lotka-Volterra predator-prey system is governed by (dx)/(dt) = x(α - β y) for prey and (dy)/(dt) = y(δ x - γ) for predators. What are the coordinates of the non-trivial equilibrium point (x^*, y^*) where (dx)/(dt) = 0 and (dy)/(dt) = 0, and how is the predator oscillation wave y(t) phase-shifted relative to the prey wave x(t)?
Selected answer Option B
Setting (dx)/(dt) = 0 and (dy)/(dt) = 0 for x > 0, y > 0 yields α - β y^* = 0 ⇒ y^* = α/β and δ x^* - γ = 0 ⇒ x^* = γ/δ. Remarkably, the average prey density x^* = γ/δ is governed by predator mortality and conversion efficiency, whereas average predator density y^* = α/β is governed by prey growth and predation rate (Volterra's principle). In the (x, y) phase plane, trajectories form closed orbits circulating counterclockwise around (x^*, y^*): abundant prey x fuels predator growth y with a quarter-cycle lag (≈ π/2), which then depletes prey, causing predator decline and allowing prey recovery.

Advanced Level · AP / University · Ecology: Lotka-Volterra Model
Mechanism

The Lotka-Volterra predator-prey model (1925-1926) governs the coupled population dynamics of **prey x(t) and predators y(t)** via the nonlinear system (dx)/(dt) = α x - β x y and (dy)/(dt) = δ x y - γ y, where α is prey intrinsic growth rate, β is predation rate, γ is predator mortality, and δ is trophic conversion efficiency.

Equations and conservation laws

Equilibrium occurs where (dx)/(dt) = 0 and (dy)/(dt) = 0. Solving gives Volterra's principle: **x^* = (γ)/(δ) and y^* = (α)/(β)**, meaning predator traits (γ, δ) set the time-averaged prey level while prey traits (α, β) set the average predator count.

Measurements and applications

The conserved quantity V(x,y) = δ x - γ ln x + β y - α ln y = const confines trajectories to closed orbits around (x^*, y^*) with period T ≈ (2π)/(√(αγ)), in which predator peaks lag behind prey peaks by a quarter cycle (π/2). Across trophic levels, Lindeman's 10% ecological efficiency rule dictates that only ∼ 10% of net production is transferred to the next trophic tier.

Experimental parameters and SI units
  • Prey intrinsic growth rate α: 0.5 … 2 yr⁻¹, standard value 1.1 yr⁻¹
  • Predation encounter rate coefficient β: 0.02 … 0.08, standard value 0.04
  • Predator natural mortality rate γ: 0.4 … 1.6 yr⁻¹, standard value 0.9 yr⁻¹
  • Trophic biomass conversion efficiency δ: 0.01 … 0.05, standard value 0.02
Physical model and application
Predator-prey population dynamics in mathematical ecology are governed by the coupled Lotka-Volterra differential equations: an increase in prey abundance expands the food supply and drives a predator surge lagging by one-quarter cycle, after which intense predation depletes the prey population and initiates a periodic oscillation around the equilibrium point (x^*, y^*).
