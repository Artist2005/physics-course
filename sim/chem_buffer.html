Buffer Solutions, Henderson–Hasselbalch Equation & Buffer Capacity

A conjugate acid-base pair HA / A⁻ scavenges both added protons H⁺ and hydroxide ions OH⁻, locking solution pH within a narrow physiological window.

Question
At what concentration ratio of weak acid [HA] to conjugate base salt [A-] does a buffer solution exhibit maximum buffer capacity βmax, and what is its pH at that point?
Selected answer Option B
By the Henderson-Hasselbalch equation pH = pKa + lg ([A-]/[HA]), when [HA] = [A-] the buffer neutralizes added H+ (A- + H+ → HA) and added OH- (HA + OH- → A- + H2O) equally well, reaching peak buffer capacity βmax = 0.576 Ctot at pH = pKa.

Mechanism

Buffer solutions resist changes in pH upon addition of small amounts of strong acid or base. An acidic buffer pairs a weak acid HA (such as acetic acid CH3COOH) with its conjugate base salt A- (sodium acetate CH3COONa).

Equations and conservation laws

Rearranging the acid dissociation equilibrium Ka = ([H+][A-])/([HA]) yields the Henderson-Hasselbalch equation: pH = pKa + lg ([A-])/([HA]). Added strong acid (H+) is scavenged by conjugate base ions (A- + H+ → HA), whereas added strong base (OH-) is neutralized by weak acid molecules (HA + OH- → A- + H2O), preventing drastic pH swings.

Measurements and applications

Buffer capacity β = 2.303 ([HA][A-])/([HA] + [A-]) is maximized when [HA] = [A-] (pH = pKa). In human physiology, the bicarbonate buffer (H2CO3 / HCO3-) stabilizes arterial blood pH strictly between 7.35 and 7.45.

Experimental parameters and SI units
  • Weak acid concentration [HA] (CH₃COOH): 0.05 … 0.5 mol/L, standard value 0.2 mol/L
  • Conjugate base salt concentration [A⁻] (CH₃COONa): 0.05 … 0.5 mol/L, standard value 0.2 mol/L
  • Added strong acid HCl (−) or base NaOH (+): -0.15 … 0.15 mol/L, standard value 0 mol/L
  • Acid dissociation exponent pKa: 3 … 9, standard value 4.76
Physical model and application
A buffer acts like a shock absorber: one drop of strong acid plunges pure water from pH 7 to 2, whereas the conjugate pair HA / A- absorbs added H+ or OH- and keeps pH rock-steady (just as blood maintains pH 7.40).
