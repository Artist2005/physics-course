Reaction Orders (0th, 1st & 2nd Order), Rate Laws & Half-Life t₁/₂

The kinetic order of a reaction reveals the true molecular mechanism hidden behind the overall stoichiometric equation.

Question
How does the half-life t1/2 depend on the initial reactant concentration [A]0 for reactions of zero (n=0), first (n=1), and second (n=2) kinetic order?
Selected answer Option B
Integrating the differential rate law -(d[A])/(dt) = k[A]n yields three distinct concentration profiles: 0th order (n=0, saturated heterogeneous catalysis): [A](t) = [A]0 - kt, t1/2 = ([A]0)/(2k); 1st order (n=1, unimolecular decay): [A](t) = [A]0 e-kt, t1/2 = ( ln 2)/(k) ≈ (0.693)/(k) (independent of [A]0); 2nd order (n=2, bimolecular collisions): (1)/([A](t)) = (1)/([A]0) + kt, t1/2 = (1)/(k[A]0).

Advanced Level · AP / University · Rate Laws & Half-Life
Mechanism

The **reaction order n** in the differential rate law v = -(d[A])/(dt) = k[A]n dictates both the integrated concentration decay [A](t) and the scaling of the **half-life t1/2** with initial concentration [A]0.

Equations and conservation laws

For **zero-order kinetics (n=0)** (e.g., surface-saturated catalysis), rate is constant (v = k), [A](t) = [A]0 - kt, and t1/2 = ([A]0)/(2k) ∝ [A]0. For **first-order kinetics (n=1)**, decay is exponential [A](t) = [A]0 e-kt and the half-life **t1/2 = ( ln 2)/(k) is strictly independent of [A]0**.

Measurements and applications

For **second-order kinetics (n=2)** (bimolecular collisions 2A → P), (1)/([A](t)) = (1)/([A]0) + kt (linear in 1/[A] vs. t) and the half-life scales inversely with initial concentration: t1/2 = (1)/(k[A]0).

Experimental parameters and SI units
  • Reaction order n (0 = zero, 1 = first, 2 = second): 0 … 2, standard value 1
  • Initial reactant concentration [A]₀: 0.5 … 3 mol/L, standard value 2 mol/L
  • Rate constant k: 0.1 … 1 s⁻¹, standard value 0.35 s⁻¹
  • Reaction time t: 0 … 6 s, standard value 2 s
Physical model and application
Reaction order governs how half-life t1/2 depends on initial reactant concentration [A]0: in a 0th-order surface-saturated reaction, rate is constant and t1/2 = ([A]0)/(2k); in 1st-order decay, half-life t1/2 = ( ln 2)/(k) is strictly concentration-independent; and in 2nd-order bimolecular kinetics, dilution slows pair collisions so t1/2 = (1)/(k[A]0) grows inversely with [A]0.
