Кінетичні рівняння нульового, першого та другого порядків і період напівперетворення t₁/₂

"Порядок реакції розкриває справжній молекулярний сценарій перетворення, прихований за підсумковим стехіометричним рівнянням", Якоб Вант-Гофф.

Питання
Для реакції якого кінетичного порядку n період напівперетворення t1/2 (час, за який реагує рівно половина вихідної речовини) не залежить від початкової концентрації реагента [A]0?
Ваша відповідь Варіант Б
Інтегрування диференціального кінетичного закону -(d[A])/(dt) = k[A]n дає три фундаментальні залежності: 1) при **n = 0** (гетерогенний каталіз при насиченні поверхні) швидкість постійна v = k, концентрація спадає лінійно [A] = [A]0 - kt, а t1/2 = ([A]0)/(2k) прямо пропорційний [A]0; 2) при **n = 1** (мономолекулярний розпад N2O5, радіоактивний розпад) швидкість v = k[A], концентрація спадає експоненційно [A] = [A]0 e-kt, а період напівперетворення **t1/2 = ( ln 2)/(k) = const** не залежить від [A]0; 3) при **n = 2** (бімолекулярна взаємодія 2HI → H2 + I2) лінійною є обернена концентрація (1)/([A]) = (1)/([A]0) + kt, а t1/2 = (1)/(k[A]0) зростає зі зменшенням концентрації.

Механізм явища

**Кінетичний порядок реакції n** у диференціальному законі діючих мас v = -(d[A])/(dt) = k[A]n показує, як миттєва швидкість перетворення реагенту залежить від його поточної молярної концентрації [A](t), і визначає закон зміни концентрації в часі та формулу **періоду напівперетворення t1/2**.

Рівняння і закони збереження

1) **Нульовий порядок (n=0)**, характерний для гетерогенного та ферментативного каталізу при повному насиченні поверхні каталізатора: швидкість стала v = k, концентрація спадає лінійно [A](t) = [A]0 - kt, а час напівперетворення прямо пропорційний початковій концентрації: t1/2 = ([A]0)/(2k).

Вимірювання і застосування

2) **Перший порядок (n=1)**, мономолекулярний розклад та радіоактивний розпад: [A](t) = [A]0 e-kt (лінеаризується у координатах ln [A] від t), а період напіврозпаду **t1/2 = ( ln 2)/(k) ≈ (0.693)/(k) взагалі не залежить від [A]0. 3) Другий порядок (n=2)**, бімолекулярні зіткнення 2A → P: (1)/([A](t)) = (1)/([A]0) + kt, а t1/2 = (1)/(k[A]0) обернено пропорційний початковій концентрації.

Фізичні параметри установки та одиниці СІ
  • Кінетичний порядок реакції n (0: нульовий, 1: перший, 2: другий): 0 … 2, типове значення 1
  • Початкова концентрація реагента [A]₀: 0.5 … 3 моль/л, типове значення 2 моль/л
  • Константа швидкості реакції k: 0.1 … 1 с⁻¹, типове значення 0.35 с⁻¹
  • Час перебігу реакції в реакторі t: 0 … 6 с, типове значення 2 с
Фізична модель і застосування
Кінетичний порядок реакції визначає характер залежності періоду напівперетворення t1/2 від початкової концентрації реагенту [A]0: для реакції 0-го порядку на насиченій поверхні каталізатора швидкість стала й t1/2 = ([A]0)/(2k); для мономолекулярної реакції 1-го порядку t1/2 = ( ln 2)/(k) не залежить від концентрації; а для бімолекулярної реакції 2-го порядку зменшення концентрації уповільнює парні зіткнення і подовжує t1/2 = (1)/(k[A]0).
